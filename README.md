# GhostSync Suite 🛡️

A modular, hardened security auditing, encrypted vault, and threat intelligence suite engineered specifically for Android/Termux environments.

## 🚀 Key Features
- **LAN & Localhost Auditing**: Rapid network mapping with color-coded risk indicators (`HIGH` for unauthenticated ADB `5555`, `WARN` for cleartext HTTP, `SAFE` for SSH).
- **Hardened Vault**: Symmetric Fernet/AES encryption for single files and full archives (`.tar.gz.enc`) with optional secure shredding (`--shred`).
- **Cryptographic Integrity & PIN**: SHA-256 Master PIN protection with strict POSIX permission lockdown (`0600`/`0700`) and vault corruption checks.
- **AI-Powered Diagnostics**: Security recommendations generated by Gemini API with an autonomous local heuristics engine fallback.
- **Reporting & Dashboards**: Generates dark-mode responsive HTML dashboards with direct preview via `termux-open`.
- **Live Net-Radar & Storage Analytics**: Active socket connection inspection and vault capacity breakdowns.
- **Key Recovery & Cloud Sync**: Password-derived PBKDF2 master key backup and zero-knowledge synchronization via `rclone`.

## Features
- **Network Audit**: Fast LAN discovery, open port detection (ADB 5555, SSH 8022/22, HTTP/HTTPS).
- **Vault Engine**: Symmetric AES/Fernet encryption for sensitive files (`storage/vault/`).

## Architecture
- `core/`: Global configurations and structured logging.
- `modules/net_audit.py`: LAN scanner and socket auditing.
- `modules/vault.py`: Cryptographic key management and encryption.
- `modules/ai_engine.py`: Security reporting and risk evaluation.
- `modules/sync_engine.py`: Remote cloud synchronization.
